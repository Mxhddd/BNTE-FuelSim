# BNTE FuelSim

BNTE FuelSim is a production-grade digital twin for a bimodal nuclear-thermal + electric (BNTE) propulsion stage. The tool evaluates the coupled hot-gas, feed, electrical, cryogenic, plume, and mission performance elements, reproducing the baseline values specified for the reference architecture while enabling trade sweeps.

## Installation

```bash
pip install -e .
```

## Running the baseline case

```bash
bnte run --cfg configs/baseline.yml
```

## Additional configurations

Additional YAML configurations enable common trades:

- `configs/good_mli.yml` – lower heat leak for improved MLI.
- `configs/ep_50kw.yml`, `configs/ep_100kw.yml`, `configs/ep_200kw.yml` – EP operating points at 50/100/200 kW.
- `configs/zbo_on.yml`, `configs/zbo_off.yml` – toggled zero-boil-off cases.
